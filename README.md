# Freelance Tracker

Static personal tracker for GitHub Pages. Includes tasks, short/long-term work, deadlines, USD/revenue pay, recurring ZAR subscriptions, goals in ZAR/USD, filtering, sorting, completion cleanup after 2 days, and JSON backup/import.

## Install
Upload every file to the root of a GitHub repository. The homepage is exactly `index.html`. Enable GitHub Pages from Settings → Pages → Deploy from branch → root.

## Data
Data is saved with browser `localStorage`. It persists when you leave the website, but it is tied to that browser/device. Clearing site data can erase it. Use Export Backup regularly.
